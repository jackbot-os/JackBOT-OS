JackBOT OS 2.0 — "Moscow River"
================================

Release tag: v2.0
Date: 2026-11-23

This is the first two-architecture release of JackBOT OS: an AArch64 build and
an x86_64 hybrid ISO.

x86_64 — JackBOT-2.0-full.iso
-----------------------------
64-bit BIOS + UEFI hybrid ISO, built 2026-11-21. The GRUB menu offers:

  * Try JackBOT OS 2.0 (Live Desktop) — full desktop with no disk and no install
  * Install JackBOT OS                  — native graphical installer
  * FAT Disk Self-Test                  — headless regression entry

gfxpayload negotiates up to 3840x2160x32. The build keeps the graphical
installer, the 205 setup languages with real TrueType fonts, the GPU-composited
hardware cursor, the TLS 1.2 HTTPS client (certificate chain parsed but not
validated against a trust store, TLS 1.3 not implemented), the AMD PCnet NIC
driver and the 231-ID PCI compatibility table. Many compatibility entries are
detection probes rather than full drivers; AHCI/SATA, NVMe and e1000e command
queues are not driven. Test in a virtual machine (VirtualBox, 2048 MB, VMSVGA,
PS/2 mouse) before using real hardware.

AArch64 (ARM64) — flash package
-------------------------------
Bare-metal AArch64 bring-up on QEMU "virt" with ramfb. Our own BL1/BL2 loader
hands control to our own AArch64 kernel: PL011 console, GIC-400, generic timer,
MMU, framebuffer desktop, phone-style status bar, notification shade with five
working toggles, dialer/SMS over the AT stack (local modem simulator), and a
first-boot wizard persisted to a virtio-blk disk.

Honest boundaries:
  * targets QEMU virt only. It is NOT Mi Pad 4 (clover) firmware and will not
    boot on that hardware; an unlocked bootloader would still be required.
  * no Wi-Fi/Bluetooth radio in the target: those toggles only change state.
  * the phone/SMS paths are proven against the local AT simulator, not a real
    baseband.
  * no map data bundle; camera, music player and file manager are not
    implemented in this build.

Running the ARM64 image
-----------------------
  qemu-system-aarch64 -M virt -cpu cortex-a53 -m 256 \
      -kernel JackBOT-OS-2.0-arm64.img -device ramfb
