JackBOT OS 2.0 — "Moscow River"
================================

Release tag: v2.0
Date: 2026-11-23

This is the first two-architecture release of JackBOT OS.

AArch64 (ARM64) — new in 2.0
----------------------------
Bare-metal AArch64 bring-up on QEMU "virt" with ramfb. Our own BL1/BL2
loader hands control to our own AArch64 kernel: PL011 console, GIC-400,
generic timer, MMU, framebuffer desktop, phone-style status bar, notification
shade with five working toggles, dialer/SMS over the AT stack (local modem
simulator), and a first-boot wizard persisted to a virtio-blk disk.

Honest boundaries:
  * targets QEMU virt only. It is NOT Mi Pad 4 (clover) firmware and will not
    boot on that hardware; an unlocked bootloader would still be required.
  * no Wi-Fi/Bluetooth radio in the target: those toggles only change state.
  * the phone/SMS paths are proven against the local AT simulator, not a real
    baseband.
  * no map data bundle; camera, music player and file manager are not
    implemented in this build.

x86_64 — unchanged at 1.0.9
--------------------------
The x86_64 channel is still the 1.0.9 build (built 2026-11-13): graphical
installer, 205 setup languages, GPU-composited hardware cursor, TLS 1.2
HTTPS client, AMD PCnet NIC driver, 231-ID PCI compatibility table.
A 2.0 x86_64 image has NOT been compiled yet, so this ISO keeps its real
name and real version instead of being relabelled.

Running the ARM64 image
-----------------------
  qemu-system-aarch64 -M virt -cpu cortex-a53 -m 256 \
      -kernel JackBOT-OS-2.0-arm64.img -device ramfb
