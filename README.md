JackBOT OS — official website
=============================

This repository holds the published website for JackBOT OS 1.0.9 (EastLake)
and the download page for the release image. It is intentionally limited to
the site: no source code is published here.

- `index.html` — the official site (single self-contained page)
- `images/` — screenshots and brand assets used by the page
- `RELEASE-1.0.9.txt` — what the 1.0.9 build does, its checksum and its limits
- `JackBOT-1.0.9.iso` — attached to the v1.0.9 release, not stored in the tree

Live site: https://jackbot-os.github.io/JackBOT-OS/
Release:  https://github.com/jackbot-os/JackBOT-OS/releases/tag/v1.0.9
