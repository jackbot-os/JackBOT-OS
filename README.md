JackBOT OS — official website
=============================

This repository holds the published website for JackBOT OS 2.0 ("Moscow River")
and the download page for the release images. It is intentionally limited to
the site and release packaging: no source code is published here.

- `index.html` — the official site (single self-contained page)
- `images/` — screenshots and brand assets used by the page
- `version.json` — machine-readable version, asset names, sizes and SHA-256
- `RELEASE-2.0.txt` — what the 2.0 release contains, its checksums and its limits
- `LICENSES/` — HJMA proprietary licence, GPL third-party list, AOSP RIL audit
- `JackBOT-OS-2.0-arm64-flash.zip` / `.img` / `boot.img` — ARM64 flash package,
  attached to the v2.0 release
- `JackBOT-1.0.9.iso` — the x86_64 image (still the 1.0.9 build), attached to
  the v2.0 release; it is not stored in the tree

Live site: https://jackbot-os.github.io/JackBOT-OS/
Release:  https://github.com/jackbot-os/JackBOT-OS/releases/tag/v2.0
